amazon.add_product_to_wish_list  [POST /amazon/wish_list/{product_id}]
Add product by id and quantities to your wish list.
  - product_id (integer, required): ID of the product to be added to the wish list.
  - access_token (string, required): Access token obtained from amazon app login.
  - quantity (integer, optional): The quantity of the product to be added to the wish list.
  - clear_wish_list_first (boolean, optional): If true, the wish list will be cleared before adding the product to the wish list.
  response: {"message": "string"}
