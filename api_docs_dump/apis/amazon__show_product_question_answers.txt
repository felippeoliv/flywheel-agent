amazon.show_product_question_answers  [GET /amazon/products/{question_id}/question_answers]
Get a list of answers to a product question.
  - question_id (integer, required): ID of the product question.
  - query (string, optional): The search query string
  - user_email (string, optional): Email of the user who posted the answer
  - is_verified (boolean, optional): Filter answers by whether they from a verified purchaser or not.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  - sort_by (string, optional): The attribute to sort the question answers by prefixed with +/- to reflect ascending/descending. Valid attributes: created_at. If both query and sort_by are given and non-empty, results will be first ranked by query relevance, then paginated, and will then be sorted by the given attribute within each page.
