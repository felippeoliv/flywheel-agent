amazon.show_product_reviews  [GET /amazon/products/{product_id}/reviews]
Get a list of product reviews.
  - product_id (integer, required): ID of the product to show reviews for.
  - query (string, optional): The search query string.
  - user_email (string, optional): Email of the user to filter reviews by.
  - min_rating (integer, optional): The minimum rating for a review.
  - max_rating (integer, optional): The maximum rating for a review.
  - is_verified (boolean, optional): Filter reviews by whether they from a verified purchaser or not.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  - sort_by (string, optional): The attribute to sort the product reviews by prefixed with +/- to reflect ascending/descending. Valid attributes: rating and created_at. If both query and sort_by are given and non-empty, results will be first ranked by query relevance, then paginated, and will then be sorted by the given attribute within each page.
