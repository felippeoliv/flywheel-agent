amazon.show_returns  [GET /amazon/returns]
Get a list of your product returns.
  - access_token (string, required): Access token obtained from amazon app login.
  - order_id (integer, optional): ID of the order to filter returns by.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  - sort_by (string, optional): The attribute to sort the product returns by prefixed with +/- to reflect ascending/descending. Valid attributes: quantity, initiated_at and returned_at.
