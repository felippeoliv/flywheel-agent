phone.search_contacts  [GET /phone/contacts]
Search your contact book for relatives' information.
  - access_token (string, required): Access token obtained from phone app login.
  - query (string, optional): Search query for the contacts list.
  - relationship (string, optional): Relationship with the person in the contacts list to filter by.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  response: [{"contact_id": 1, "first_name": "string", "last_name": "string", "email": "user@example.com", "phone_number": "string", "relationships": ["string"], "birthday": "string", "home_address": "string", "work_address": "string", "created_at": "2019-01-01T00:00:00"}]
