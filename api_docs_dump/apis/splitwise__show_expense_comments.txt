splitwise.show_expense_comments  [GET /splitwise/expenses/{expense_id}/comments]
Get a list of expense comments.
  - expense_id (integer, required): The ID of the expense.
  - access_token (string, required): Access token obtained from splitwise app login.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  response: [{"expense_comment_id": 1, "expense_id": 1, "comment": "string", "created_at": "2019-01-01T00:00:00", "user": {"name": "string", "email": "user@example.com"}}]
