splitwise.show_payment_comment  [GET /splitwise/payment_comments/{comment_id}]
Get information about a comment posted on a payment.
  - comment_id (integer, required): The ID of the payment comment.
  - access_token (string, required): Access token obtained from splitwise app login.
  response: {"payment_comment_id": 1, "payment_id": 1, "comment": "string", "created_at": "2019-01-01T00:00:00", "user": {"name": "string", "email": "user@example.com"}}
