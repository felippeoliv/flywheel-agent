spotify.add_song_to_playlist  [POST /spotify/playlists/{playlist_id}/songs/{song_id}]
Add a song to a playlist.
  - playlist_id (integer, required): The playlist id to add the song to.
  - song_id (integer, required): The song id to add.
  - access_token (string, required): Access token obtained from spotify app login.
  response: {"message": "string"}
