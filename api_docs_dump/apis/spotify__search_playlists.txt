spotify.search_playlists  [GET /spotify/playlists]
Search for playlists with a query. It will search over all public playlists and your own private playlists.
  - access_token (string, required): Access token obtained from spotify app login.
  - query (string, optional): The search query string.
  - min_like_count (integer, optional): The minimum like count for search results.
  - max_like_count (integer, optional): The maximum like count for search results.
  - min_rating (number, optional): The minimum rating for search results.
  - max_rating (number, optional): The maximum rating for search results.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  - sort_by (string, optional): The attribute to sort the playlists by prefixed with +/- to reflect ascending/descending. Valid attributes: like_count, rating and created_at. If both query and sort_by are given and non-empty, results will be first ranked by query relevance, then paginated, and will then be sorted by the given attribute within each page. If both query and sort_by are not given, null, or empty, sort_by will default to -like_count.
