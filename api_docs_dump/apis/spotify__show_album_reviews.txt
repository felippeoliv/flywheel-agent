spotify.show_album_reviews  [GET /spotify/albums/{album_id}/reviews]
Get a list of reviews for an album.
  - album_id (integer, required): The album id to retrieve reviews for.
  - query (string, optional): The search query string.
  - user_email (string, optional): Email of the user to filter reviews by.
  - min_rating (integer, optional): The minimum rating for a review.
  - max_rating (integer, optional): The maximum rating for a review.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  - sort_by (string, optional): The attribute to sort the album reviews by prefixed with +/- to reflect ascending/descending. Valid attributes: rating and created_at. If both query and sort_by are given and non-empty, results will be first ranked by query relevance, then paginated, and will then be sorted by the given attribute within each page.
