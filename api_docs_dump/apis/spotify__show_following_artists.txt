spotify.show_following_artists  [GET /spotify/following_artists]
Get a list of artists the user is following.
  - access_token (string, required): Access token obtained from spotify app login.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  response: [{"artist_id": 1, "name": "string", "genre": "string", "follower_count": 1, "created_at": "2019-01-01T00:00:00", "followed_at": "2019-01-01T00:00:00"}]
