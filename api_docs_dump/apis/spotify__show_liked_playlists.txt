spotify.show_liked_playlists  [GET /spotify/liked_playlists]
Get a list of playlists you have liked.
  - access_token (string, required): Access token obtained from spotify app login.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  - sort_by (string, optional): The attribute to sort the liked playlists by prefixed with +/- to reflect ascending/descending. Valid attributes: liked_at and title.
  response: [{"playlist_id": 1, "title": "string", "is_public": true, "rating": 0.0, "like_count": 1, "review_count": 1, "owner": {"name": "string", "email": "user@example.com"}, "created_at": "2019-01-01T00:00:00", "song_ids": [1], "liked_at": "2019-01-01T00:00:00"}]
