spotify.show_playlist  [GET /spotify/playlists/{playlist_id}]
Get detailed information about a specific playlist. You can view your own playlists or others' playlists if they are public.
  - playlist_id (integer, required): The playlist id to retrieve.
  - access_token (string, required): Access token obtained from spotify app login.
