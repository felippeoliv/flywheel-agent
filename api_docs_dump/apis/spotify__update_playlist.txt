spotify.update_playlist  [PATCH /spotify/playlists/{playlist_id}]
Update a playlist title or privacy.
  - playlist_id (integer, required): The playlist id to update.
  - access_token (string, required): Access token obtained from spotify app login.
  - title (string, optional): The updated title of the playlist.
  - is_public (boolean, optional): Whether the playlist is public or not.
  response: {"message": "string"}
