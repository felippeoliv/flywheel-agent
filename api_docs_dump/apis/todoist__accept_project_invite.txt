todoist.accept_project_invite  [POST /todoist/project_invites/{invite_code}/accept]
Accept an invite to join a project using an invite code generated by a project collaborator.
  - invite_code (string, required): The invite code sent to you by a project collaborator.
  - access_token (string, required): Access token obtained from todoist app login.
  response: {"message": "string", "project_id": 1}
