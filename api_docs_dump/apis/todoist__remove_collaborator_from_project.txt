todoist.remove_collaborator_from_project  [DELETE /todoist/projects/{project_id}/collaborators]
Remove a collaborator (or self) from a project.
  - project_id (integer, required): The ID of the project.
  - email (string, required): Email of the user to remove as a collaborator.
  - access_token (string, required): Access token obtained from todoist app login.
  response: {"message": "string"}
