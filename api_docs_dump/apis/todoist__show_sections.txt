todoist.show_sections  [GET /todoist/projects/{project_id}/sections]
Get a list of sections within a project.
  - project_id (integer, required): The ID of the project. You can use 0 for your Inbox project.
  - access_token (string, required): Access token obtained from todoist app login.
  response: [{"project_id": 1, "name": "string", "order_index": 0.0, "created_at": "2019-01-01T00:00:00", "section_id": 1, "num_tasks": 1}]
