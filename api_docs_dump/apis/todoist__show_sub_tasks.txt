todoist.show_sub_tasks  [GET /todoist/tasks/{task_id}/sub_tasks]
Get a list of sub_tasks within a task.
  - task_id (integer, required): The ID of the task.
  - access_token (string, required): Access token obtained from todoist app login.
  response: [{"task_id": 1, "title": "string", "description": "string", "due_date": "2019-01-01T00:00:00", "priority": "high", "is_completed": true, "duration": 0.0, "duration_unit": "minutes", "order_index": 0.0, "created_at": "2019-01-01T00:00:00", "sub_task_id": 1}]
