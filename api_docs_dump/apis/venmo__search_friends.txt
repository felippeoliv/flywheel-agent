venmo.search_friends  [GET /venmo/friends]
Search your or others' friends by name or email address.
  - access_token (string, required): Access token obtained from venmo app login.
  - query (string, optional): Search friends by name or email address.
  - user_email (string, optional): Email address of the user whose friends you want to see. If not passed, your friends will be returned.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  response: [{"first_name": "string", "last_name": "string", "email": "user@example.com", "registered_at": "2019-01-01T00:00:00", "friends_since": "2019-01-01T00:00:00"}]
