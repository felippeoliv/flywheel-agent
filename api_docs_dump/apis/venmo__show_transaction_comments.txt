venmo.show_transaction_comments  [GET /venmo/transactions/{transaction_id}/comments]
Get a list of transaction comments.
  - transaction_id (integer, required): ID of the transaction to retrieve comments for.
  - access_token (string, required): Access token obtained from venmo app login.
  - page_index (integer, optional): The index of the page to return.
  - page_limit (integer, optional): The maximum number of results to return per page.
  response: [{"transaction_id": 1, "comment": "string", "created_at": "2019-01-01T00:00:00", "like_count": 1, "comment_id": 1, "user": {"name": "string", "email": "user@example.com"}}]
